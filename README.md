## What it does

- **1 车照 + 可选徽标** → Venom 粘液车库组装短片（爬行、抓标、组装、揭晓）
- 画幅 **9:16 / 3:4 / 16:9 / 1:1**；付费成片约 **15 秒**；480p / 720p
- 音频为原创 AI 环境音，**非**商业原曲扒带
- 一次性积分包 $8.88 / $16.99 / $39.90，无订阅；硬失败自动退积分

## How to use

1. 打开 [venomcarai.cc](https://venomcarai.cc)
2. 上传 1 张清晰**整车**照片（前侧 3/4 或正面最佳）；可选上传徽标/Logo
3. 勾选授权声明 → 选画幅（建议 9:16）→ Create
4. Stripe 一次性积分包：Single **$8.88** / Popular **$16.99** / Creator **$39.90**
